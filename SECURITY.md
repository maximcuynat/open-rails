# Sécurité

## Versions prises en charge

Seule la dernière version publiée d'Open Rails reçoit des correctifs de sécurité.

## Signaler une vulnérabilité

Merci de ne pas ouvrir de ticket public pour une faille de sécurité.

Utilisez le signalement privé de GitHub : onglet **Security** du dépôt, puis **Report a vulnerability**
(https://github.com/maximcuynat/open-rails/security/advisories/new).

Décrivez le problème, la version concernée et les étapes pour le reproduire. Vous recevrez une réponse dès que
possible, et le correctif sera publié avant toute divulgation publique.
